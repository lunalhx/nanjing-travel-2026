# 景点照片

每个景点一个文件夹，把该景点的所有照片放进对应文件夹即可；文件名可以保留原样，只要格式是 `.jpg`、`.jpeg`、`.png` 或 `.webp`。详情预览会依文件名顺序显示全部照片，可以用左右按钮切换。当前有些景点文件夹还是空的，它们只是待上传位置，空文件夹不会生成照片；网页预览会显示“照片尚未添加”。

上传完成后，在项目根目录运行 `npm run build` 检查图片格式，再把改动提交并推送到 GitHub；Pages 工作流会自动发布。网页本身不提供上传入口，因为 GitHub Pages 是静态托管，手机浏览器不能通过网页把照片写回仓库。

网页会按原始比例完整显示，不裁切、不拉伸。建议使用长边约 1600–2400 像素的 JPG 或 WebP，避免上传相机原片造成页面过慢。竖图、横图和方图都可以。
