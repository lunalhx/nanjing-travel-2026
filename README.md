# 南京旅行选择册

手机优先的南京景点选择页面，日期为 2026 年 10 月 24 日至 26 日。分上午、下午和晚上安排；同一天相邻时段的片区必须相同或相邻。梧桐大道作为钟山片区的散步拍照选项，秦淮街区、画舫及新街口晚餐列入夜间选项。已选景点不能在其他时段重复安排。

景点条目说明适合的活动类型与预计游览时长。移动时间按所选景点间的较短建议次序计算区间，不依赖添加顺序；常见邻近点位用单独区间，其余按片区估算。不含出发地至首个景点的路程。游览时长和移动时间都是低可信度的人工攻略粗估，不是地图导航或实时路况。时段预算使用移动时间区间的上限，作为取舍提示。

每个人在自己的设备上输入昵称、标记参加日期并选择景点。用“下载我的选择”导出个人 JSON 文件，发到群里；收到群友的文件后，在“同行选择”里导入。汇总文件会包含目前已导入的所有人，方便继续转发。选择数据保存在浏览器本机；GitHub Pages 本身不提供自动同步。

照片放在 `public/photos/<景点中文名>/`，景点文件夹已按中文名称创建。支持同一景点多张 JPG、PNG 或 WebP；预览会按文件名排序显示，不裁切、不拉伸。详情中的“加入当前时段”与预览相互独立。图片准备说明见 `public/photos/README.md`。

本地启动：

```sh
npm test
npm run build
npx --yes serve dist
```

推送到 `main` 后，GitHub Actions 会自动构建并发布到 GitHub Pages：

https://lunalhx.github.io/nanjing-travel-2026/

首次发布前，在仓库 Settings → Pages 里把 Source 设为 **GitHub Actions**。工作流文件是 `.github/workflows/pages.yml`。
